# Changelog

## 0.1.0 — 2026-10-27

- Local-only API for creating and listing assets and borrowers, borrowing, returning and filtering loans/availability.
- Transactional stock and duplicate-loan checks, SQLite schema validation and explicit limits.
- OpenAPI 3.0.3 document, synthetic local demo, tests, CI and bilingual overview.
- No authentication or authorization; not a production or publicly writable deployment.
